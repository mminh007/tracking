# :rocket: Tracking objects in low-light conditions

:mag_right: Tracking objects in low-light conditions presents significant challenges due to poor image quality, noise, and reduced contrast, impacting the accuracy of traditional object tracking algorithms. Some methods, such as noise reduction, low-light enhancement, and algorithms for learning invariant features in low-light environments, can address these issues.

:mag_right: In this repo, I experimented with several methods to improve the output quality of the problem. I applied Denoising and Low-Light Enhancement techniques along with Synthetic Datasets.
